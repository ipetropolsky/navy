# Пользовательский флоу и места кнопок

Предложение последовательной структуры интерфейса: почему сейчас «всё раскидано»,
какой моделью это чинится и что именно переставить. По состоянию `97664ea`.

## Диагноз

Зоны экрана спроектированы хорошо (сцена / разговор / слои / модальные шторки —
см. SHEETS.md), а вот **входы в действия** протоптаны там, где нашлось место:

- «Уйти с рейда» живёт в двух местах, и оба неожиданные: кнопка в шапке, которая
  существует только пока открыта форма корабля (App.tsx:943), и полоса внизу
  списка кораблей (MembersList.tsx:235).
- Приглашение («Координаты») — на дне списка кораблей. А нужнее всего оно
  создателю пустого канала, который в список ещё и не заглянет: звать некого,
  список пуст.
- Настройка своего корабля — тычок по своему силуэту на сцене (новичок не
  догадается) или «Настроить корабль» из списка. Постоянной точки «я» в
  интерфейсе нет.
- Шапка непредсказуема: кнопки в ней появляются и исчезают по состоянию
  (уход — при открытой форме, панель — только сбоку). Непостоянная шапка и есть
  главный источник ощущения хаоса: место, куда смотрят за ориентиром, само
  меняется.

## Модель: три объекта — три дома

У приложения три объекта, с которыми что-то делают. Каждому — ровно один «дом»,
и каждое действие живёт в доме своего объекта:

| Объект | Дом | Действия в нём |
| --- | --- | --- |
| **Канал** (рейд целиком) | список кораблей | кто на связи, позвать, оклик, уйти с рейда |
| **Мой корабль** | форма корабля | силуэт, цвет, номер, позывной, место, курс |
| **Чужой корабль** | карточка | разглядеть, сигнал, (старшему — высадить из списка) |

Правила, которые делают флоу предсказуемым:

1. **Шапка постоянна.** Один и тот же состав кнопок во всех состояниях канала;
   ничего не появляется и не исчезает. Шапка — только входы в «дома», не действия.
2. **Действие — в доме объекта.** Новая фича сначала получает дом, потом место
   в полосе действий этого дома (`Actions`). Если дом неочевиден — фича ещё
   не продумана.
3. **Закрыл — вернулся, откуда открыл.** Уже соблюдается (`cover`); не ломать.
4. **Одна полоса действий на дом**, внизу (уже есть `Actions`) — не рассыпать
   кнопки по телу шторки.

## Что переставить

### Шапка: два постоянных входа

```
[Название канала + статус]                    [◉ 042]  [панель]
 ← дом канала (список)                        ← дом «я»  (только сбоку)
```

- **Слева** — как сейчас: весь блок названия открывает список кораблей. Это дом
  канала, вход на месте.
- **Справа — аватарка своего корабля** (тот же кружок с бортовым номером, что
  в ленте): постоянный вход в форму своего корабля. Привычный паттерн «профиль
  в правом верхнем углу», и «я» перестаёт прятаться в силуэте на сцене. Тычок
  по своему кораблю на сцене остаётся — как приятный второй вход, а не
  единственный.
- **Кнопку «Уйти с рейда» из шапки убрать** (App.tsx:940–945): уход переезжает
  в единственный дом — список кораблей. Заодно шапка перестаёт меняться от
  открытия формы.
- Кнопка панели — только в боковой раскладке, как сейчас: она про раскладку,
  а не про канал, и на телефоне её нет — это правильно.
- Гостю (до входа в строй) шапка показывает те же два блока, но правый — кнопка
  «Встать на рейд» вместо аватарки: одно и то же место отвечает на вопрос
  «кто я здесь» в обоих состояниях.

### Список кораблей = хаб канала

Сверху вниз:

1. Заголовок (как сейчас).
2. **«Позвать корабли» — первой строкой, primary**, а не secondary на дне:
   пока на рейде меньше двух кораблей, это главное действие канала вообще.
   С полным рейдом (5/5) строка исчезает — звать некуда.
3. Строки экипажа (как сейчас: свой → форма, чужой → карточка, аватарка → оклик,
   старшему — высадка).
4. Полоса внизу: **«Уйти с рейда»** (danger) — единственное место ухода.

### Пустой канал: приглашение навстречу

Создатель только что созданного канала видит пустой рейд и «никого нет» в статусе.
Сделать статусную строку живой: «никого нет — позвать корабли» (нажатие — та же
копия координат + снекбар). Это единственный момент, где действие канала уместно
прямо в шапке, — и оно исчезает с первым вошедшим. Альтернатива, если живой статус
кажется перегрузом: после создания канала открывать список кораблей сразу — пусть
«Позвать» первой строкой встретит сам.

### Форма корабля: только настройки

Из формы уходит дублирующий вход в «уйти» (сейчас — кнопка в шапке, видимая только
при форме). Форма отвечает на один вопрос — «каким кораблём я стою», — и у неё
свои две кнопки: «В строй» / «Отмена». Меньше вопросов на экран — понятнее каждый.

### Лента: добраться до нового

«↓ к новым» — плавающая кнопка над композером, когда лента отмотана вверх
(и, позже, с бейджем непрочитанного). Сейчас, читая старое, о новых сообщениях
не узнать никак — см. REVIEW §Продукт.

## Что НЕ трогать

- Тычки по сцене (свой → форма, чужой → карточка) — это прелесть проекта;
  они остаются быстрыми входами для тех, кто их нашёл. Правка выше лишь даёт
  каждому входу дублёра в предсказуемом месте.
- Механику слоёв и шторок — она описана в SHEETS.md и с флоу не конфликтует.
- Композер, ответы, оклик по аватарке — работают по привычным паттернам.
